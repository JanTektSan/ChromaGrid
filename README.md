# Chroma Grid

Developed by [jantektsan](https://github.com/JanTektSan)

A block puzzle game for Android. It has no ads, no tracking and doesn't use the internet.

Drag pieces onto an 8×8 board. When a row or column is full, it clears and you score points. Keep clearing lines on moves close together to build a combo. The game ends when none of your pieces fit on the board.

## Download and install

1. Download [ChromaGrid.apk](ChromaGrid.apk). On the file page, choose **Download raw file**.
2. Open the file on your Android phone.
3. If your phone asks, allow your browser or file manager to install unknown apps.
4. Tap **Install**.

You need Android 8.0 or newer.

## How to play

- **Placing pieces:** drag one of the three pieces at the bottom onto the board. A shadow shows where it will land, and any lines it would complete glow.
- **Points:** each block you place is worth 1 point. Clearing several lines at once scores much more, for example 10 for one line, 40 for two and 90 for three.
- **Combos:** if you clear lines again within 3 moves, you start or keep a combo. The combo number multiplies the points you get for clearing lines.
- **Board Clear:** emptying the whole board gives a +300 bonus.
- **New pieces:** when you've used all three pieces, you get three new ones. Pieces that don't fit anywhere are shown faded.
- **Saving:** your best score and the game in progress are saved automatically.
- **Buttons:** ♪ turns sound on or off. To start a new game, tap ↻ twice.

## Building from source

You need Windows, a JDK (17 or newer), and the Android SDK with `platforms;android-35` and `build-tools;35.0.0` installed. The build script looks for the SDK in `ANDROID_HOME`, or in `%LOCALAPPDATA%\Android\Sdk` if that variable isn't set. Gradle isn't needed.

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1            # build ChromaGrid.apk
powershell -ExecutionPolicy Bypass -File build.ps1 -Install   # build and install on a phone connected over USB
```

The first time you build, the script creates a signing key called `debug.keystore`. Git doesn't track this file. Back it up, because updates install over the existing app only when they're signed with the same key.

## Project layout

| Path | What it holds |
|------|---------------|
| `app/src/.../GameView.java` | Board, gameplay, scoring, drawing and touch input |
| `app/src/.../Shapes.java` | Piece shapes and how new piece sets are chosen |
| `app/src/.../Sfx.java` | Sound effects, which are generated by code when the app runs |
| `app/src/.../MainActivity.java` | Full-screen activity; saves the game when you leave the app |
| `app/res/` | App name and launcher icon |
| `build.ps1` | Build script (aapt2, javac, d8, zipalign, apksigner) |
